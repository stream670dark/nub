# Nub

> ⚠️ Under development — not recommended for production use yet.

Nub is a high-level programming language designed to let you write code
fast, with clean ergonomics, without worrying about memory management
or pointers — just logic.

The language aims to be a good fit for game scripting, web, backend,
math, and more.

---

This is my first real open-source project. My goal is to learn and
build a community around Nub. Contributions and feedback are welcome.
